# 色板登记表

全项目共用同一批配色。**同一个色板 = 同一个配色家族**，只是换了物件。
素材命名统一按家族色叫（绿 / 蓝 / 紫 / 金 / 红 / 棕 / 灰 …），不按物件单独起名。

> 重新扫描：`python3 tools/scan_palettes.py`

### 背景渐变专用色

4 族背景渐变各有一套 4 档纯色，只给 `background/` 用：

| 族 | 4 档 |
|---|---|
| `sky` | `#FFFFFF` → `#1498DC` → `#1950C0` → `#032659` |
| `warm` | `#FAD3B3` → `#F49990` → `#FFD233` → `#F99C0B` |
| `purple` | `#F49990` → `#E65F69` → `#B73D94` → `#6F2C77` |
| `stone` | `#D7DEE8` → `#AEB4CE` → `#838BA9` → `#636B85` |

其中 `#1498DC`（sky 第 2 档）和 `#F49990`（warm 第 2 档 / purple 第 1 档）、
`#F99C0B`（warm 第 4 档）、`#B73D94`（purple 第 3 档）、`#6F2C77`（purple 第 4 档）、
`#AEB4CE`（stone 第 2 档）、`#636B85`（stone 第 4 档）和别的族共用。

## 命名对照

同一个色板在不同素材里历史上用过不同叫法，统一成左边这套：

| 统一叫法 | 旧的叫法 | 说明 |
|---|---|---|
| 紫 | mushroom 的 `pink`、fruit 的 `pink` | 和药瓶 `potion_purple`、史莱姆紫同板 |
| 金 | fruit 的 `orange` | 和药瓶 `potion_gold`、蘑菇金同板 |
| 绿 | — | 绿系有 3 套板：草绿、药瓶绿、蘑菇绿，按用途区分 |
