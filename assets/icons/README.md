# 图标

## icon.png —— 项目图标（封面）

`project.godot` 里的 `config/icon` 指向它。**别手改**，改完重跑生成脚本：

```bash
python3 tools/make_icon.py
```

### 画面构成

128×128，圆角方形（半径 22），三层叠出来：

| 层 | 内容 | 来源 |
|---|---|---|
| 背景 | 天空竖直渐变 `#1498DC` → `#1950C0` | 天空族第 2 / 第 3 档（见 PALETTE.md） |
| 地面 | 一条草皮 | `tilesets/world/tiles/grass_dirt.png` 的前 8 行 |
| 主体 | 骑士 idle 姿势，5 倍最近邻放大 | `sprites/knight/idle/idle_00.png` |

### 几个注意点

- **必须用最近邻放大**。插值会把硬边像素画糊掉，缩小后边缘会发虚。
- 骑士是**裁到不透明包围盒**再放大的，`idle_00` 原本 32×32 画布里角色只占 13×19，
  不裁的话四周的空白会把角色缩得很小。
- 地面砖的最左最右两列是透明的（地形边缘用的），横向拼会漏缝，
  所以脚本里去掉了这两列，并且先把底铺成描边色 `#231C19` 再贴砖。
- 圆角外的像素是完全透明的，Godot 导入时 `fix_alpha_border` 会把旁边的天空色
  渗进这些透明像素的 RGB 通道里（防滤波黑边）——不影响显示，比对时要只比可见像素。

### 配色

全部取自 [PALETTE.md](../PALETTE.md)，没有新配色：天空用天空族，草地用草绿族，
描边用灰族暗色，骑士沿用它自己那套专属色板。
