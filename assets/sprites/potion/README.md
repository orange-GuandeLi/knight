# 药瓶

4 种颜色的药瓶，静态单帧。

## 文件

| 颜色 | 文件 |
|---|---|
| 绿 | `potion_green.png` |
| 金 | `potion_gold.png` |
| 蓝 | `potion_blue.png` |
| 紫 | `potion_purple.png` |

## SpriteFrames

`potion_frames.tres`，4 个动画，每个都是 1 帧 / 8 fps / 循环：

| 动画名 | 帧数 | fps | 循环 |
|---|---|---|---|
| `green` | 1 | 8 | 是 |
| `gold` | 1 | 8 | 是 |
| `blue` | 1 | 8 | 是 |
| `purple` | 1 | 8 | 是 |

## 画法

4 张结构完全一样，只有配色不同：

| 颜色 | 描边 | 亮（高光） | 主色 | 暗（底） |
|---|---|---|---|---|
| 绿 | `#231C19` | `#03991F` | `#0A7030` | `#14462D` |
| 金 | `#231C19` | `#FFD233` | `#F99C0B` | `#FA5F00` |
| 蓝 | `#242B33` | `#A0FCD8` | `#1498DC` | `#1950C0` |
| 紫 | `#231C19` | `#E65F69` | `#B73D94` | `#6F2C77` |

瓶子本体在 x4-11（8px 宽）、y2-15：

- 瓶口：rows 2-6，4px 宽，带一圈高光。
- 瓶颈收口：row 7。
- 瓶身：rows 8-14，两侧各留 1px 描边。
- 瓶底：row 15 封口。

## 和其它素材共用色板

这张图集里不同物件复用同一批色板，认颜色时可以直接对：

- 紫色 = `#B73D94` / `#E65F69` / `#6F2C77` + 描边 `#231C19` —— 和蘑菇的紫色那套**完全相同**。
- 金色 = `#FFD233` / `#F99C0B` / `#FA5F00` + 描边 `#231C19` —— 和蘑菇的金色那套**完全相同**。
- 蓝色用冰的色板（`#1498DC` / `#A0FCD8` / `#1950C0` + 描边 `#242B33`）。
- 绿色是单独的一套（`#03991F` / `#0A7030` / `#14462D`），和蘑菇的绿色不是同一批。
