# 史莱姆 (Slime)

敌人素材。绿 / 紫两种颜色，**形状完全相同，只有颜色不同**。

## 规格

- 每帧 `14×15` PNG，透明背景，硬边像素画
- 内容固定占满宽度（x = 0..13），**底边固定贴在图底**，高度随动作在 9~15px 之间变化
  → 所有帧的脚底在同一条线上，史莱姆是「原地压扁/拉伸」，不会整体上下跳

## 源图结构

```
96x72  =  4 列 x 3 行，每格 24x24
┌────┬────┬────┬────┐
│melt│idle│hurt│    │   ← 4 列都有内容
├────┼────┼────┼────┤
│    │    │    │    │
├────┼────┼────┼────┤
│    │    │    │    │
└────┴────┴────┴────┘
内容都在格子底部居中：x = 5..18，底边 = 格子第 23 行
```

## 动画表

| 动画 | 帧数 | 帧率 | 循环 | 说明 |
|---|---|---|---|---|
| `melt` | 4 | 8 | ❌ | **单向融化**：身体从 9px 一路瘫到 12px，越瘫越薄、底部越烂。一次性播放，当死亡动画用 |
| `idle` | 4 | 8 | ✅ | **挤压拉伸呼吸**：12px → 13px → 15px（整个摊开） → 13px，是个来回循环 |
| `hurt` | 4 | 12 | ❌ | **受击闪红**：第 3 帧整个身体变红（`#E63713`），前后帧正常 |

### 各帧高度

| 帧 | melt | idle | hurt |
|---|---|---|---|
| 0 | 9px | 12px | 15px |
| 1 | 10px | 13px | 13px |
| 2 | 11px | **15px（摊开）** | 13px（**全红**） |
| 3 | 12px | 13px | 13px |

## 重复帧

12 格视觉上只有 **8 个不同**。下面 4 组是完全重复的（逐像素相同）：

| 重复 | 出现在 |
|---|---|
| `melt_03` == `idle_00` | 12px 姿态 |
| `idle_01` == `idle_03` | 13px 姿态 |
| `idle_02` == `hurt_00` | 15px 摊开姿态 |
| `hurt_01` == `hurt_03` | 13px 姿态（`hurt_02` 是它的红色版） |

> 源图里这些重复格的 **文件哈希不同，但差异全部落在透明像素的 RGB 上**（视觉不可见），
> 是导出工具的产物。三个动画各用各的帧，不用去重。

## 调色板

|---|---|---|---|---|---|
| green | `#161320` `#131320` | `#6DA200` | `#BAD200` | 白 `#F3F1E2` / 瞳 `#E63713` | |
| purple | `#120C0A` | `#6F2C77` | `#B73D94` | 白 `#EDE4DA` / 瞳 `#E63713` | 和水果里的粉色系是同一套色 |

## 在 Godot 里用

```gdscript
@onready var anim: AnimatedSprite2D = $AnimatedSprite2D
anim.sprite_frames = preload("res://assets/sprites/slime/slime_green_frames.tres")
anim.play("idle")
```

**Sprite2D 偏移**：史莱姆的脚底贴在图片底边，而图片是 `14×15`。
用默认 `centered = true` 时，图片底边在节点下方 `15/2 = 7.5`px，
所以设 `offset = (0, -7.5)` 让节点原点落在脚底（和骑士的 `offset = (0, -12)` 一个思路）。
