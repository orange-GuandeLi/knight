# 平台砖块 (Platforms)

平台/地面用的砖块素材，从一张 `64×64` 的图集切出。

## 源图结构

```
platforms.png  (64x64)
┌────┬────┬────┬────┐   每格 16x16 网格
│草地│泥土│黄金│冰块│   ← 行 0..3
├────┼────┼────┼────┤
│    │    │    │    │   ← 第 4 列全空
├────┼────┼────┼────┤
│    │    │    │    │
├────┼────┼────┼────┤
│    │    │    │    │
└────┴────┴────┴────┘
```

- 网格间距 `16×16`，但**每格只有顶部 9 行有内容**，下面 7 行是空的
- 第 4 列（x = 48~63）**完全透明**，没用上
- 4 种材质的 3 种形状**轮廓完全一致**，只有颜色不同

## 切出的素材

每片都是 `16×9`（已裁掉空白行），与源图逐像素校验一致。

```
tiles/
├── grass/   grass_block.png  grass_left.png  grass_right.png
├── dirt/    dirt_block.png   dirt_left.png   dirt_right.png
├── gold/    gold_block.png   gold_left.png   gold_right.png
└── ice/     ice_block.png    ice_left.png    ice_right.png
```

| 后缀 | 轮廓 | 含义 |
|---|---|---|
| `_block` | 两端都是圆角 | 独立一块，单独就是 1 格宽的平台 |
| `_left` | 左圆角、右平 | 平台左段 |
| `_right` | 左平、右圆角 | 平台右段 |

## 拼接规则（重要）

素材只有 3 种形状，**没有「两端都是平边」的中段砖**：

| 组合 | 结果 |
|---|---|
| `block` | ✅ 1 格平台，两端圆角 |
| `left` + `right` | ✅ 2 格平台，**接缝完全看不出来**（第 1~7 行左右两侧的描边都是连续的） |
| `left` + `left` + `right` | ⚠️ 3 格，顶部轮廓在第 2 块左上方有个 2px 缺口 |
| `right` + `right` | ❌ 接缝处明显凹进去 |

所以这套素材**直接只能拼出 1 格或 2 格宽的平台**。

要拼更宽的平台，两个办法：

1. **补一个中段砖**（推荐）——用 `right` 的平边一侧扩展出一张两端都平的 `*_mid.png`，
   颜色全部取自原图，不新增任何像素色。需要的跟我说一声就能生成。
2. 用 `Sprite2D` + `NinePatchRect` 拉伸 `block`，靠九宫格拉伸中段。

> 源图第 4 列全空，很可能是导出时丢了一列 —— 如果能找到完整图集，可能本来就有中段砖。

## 在 Godot 里用

**方案 A：TileSet 图集（推荐）**

直接拿 `platforms.png` 建 TileSet atlas，`tile_size = 16x16`，
这样 4 行 3 列的坐标就是素材原位置：

| 材质 | 左块 | 中块 | 右块 |
|---|---|---|---|
| grass | (0, 0) | (1, 0) | (2, 0) |
| dirt | (0, 1) | (1, 1) | (2, 1) |
| gold | (0, 2) | (1, 2) | (2, 2) |
| ice | (0, 3) | (1, 3) | (2, 3) |

注意用图集时每格底部有 7px 空白，**瓦片实际贴图只占上 9px**，
碰撞体要按 9px 高画而不是 16px。

**方案 B：单张 Sprite2D**

用 `tiles/` 里的独立小图，16×9 直接对齐到地面高度。

**Sprite2D 偏移**：砖块贴图顶端就是平台表面，用默认 `centered = true` 时
要把 `offset.y` 设成 `-(9/2) = -4.5`，让节点原点落在砖块**顶边**（也就是玩家站立的那条线）。
或者更省事：直接 `centered = false`，然后 `offset.y = -4.5` 换成把原点在中心对齐。

## 重新切图

```bash
python3 tools/slice_platforms.py platforms.png assets/tilesets/platforms
```

（源图在 `assets/tilesets/platforms/platforms.png`，脚本默认读项目根目录的 `platforms.png`）
