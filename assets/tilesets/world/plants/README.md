# 植物

树和草丛。树是**按语义切开的**：顶部 + body + 底部，body 可以重复任意多个，树就任意高。

## 树

三棵树的形状和配色：

| 名字 | 叶子色 | 树干 |
|---|---|---|
| `tree_green_*` | 草绿 `#03991F` / `#0A7030` / `#14462D` | 泥土 `#B66B3A` |
| `tree_gold_*` | 金 `#FFD233` / `#F99C0B` / `#FA5F00` | 泥土 `#B66B3A` |
| `tree_moss_*` | 蘑菇绿 `#51A985` / `#237B59` / `#135C41` | 紫岩 `#B56B5F` |

每棵切成三张 16×16：

| 文件 | 原图行范围 | 作用 |
|---|---|---|
| `tree_<色>_top.png` | 0-15 | 树冠圆头起始 |
| `tree_<色>_body.png` | 16-31 | 树冠中段，**可重复** |
| `tree_<色>_bottom.png` | 32-47 | 树冠收口 + 树干 |

### 为什么 body 能重复

树叶纹理的**竖向周期正好是 16px**：
`tile_13` 第 6-9 行和第 22-25 行逐像素相同，`tile_19` 第 5-15 行和第 21-31 行逐像素相同。
（`tile_13` / `tile_19` 是原始图集里的切片名，切完就没了，这里只作记录。）

所以切出来的 `body` 正好是一个完整周期，往上摞 N 张不会有接缝。实测堆叠接缝的像素差异：

| 树 | 接缝差异 | body 内部相邻行平均差异 | 结论 |
|---|---|---|---|
| `tree_green` | 0 px | 2.3 px | 无缝 |
| `tree_gold` | 0 px | 2.3 px | 无缝 |
| `tree_moss` | 9 px | 4.9 px | 无缝（在正常纹理起伏范围内） |

### 拼法

```
tree_x_top          第 y-1-bodies 行
tree_x_body     ×N  第 y-2 ... y-1-bodies+1 行   ← N 就是树高
tree_x_bottom       第 y 行（树干底，踩在地面上）
```

`bodies = 0` 就是最矮的三格树；`bodies = 3` 就是六格高的树。

## 草丛

两种颜色，每种三株**不同形状**，都是 16×16（原图里是一张 16×48 竖条塞了三株，已按连通区域拆开并底对齐到格子底部）。

| 文件 | 说明 |
|---|---|
| `grass_green_1/2/3.png` | 草绿，第 1 株最大，第 2、3 株渐小 |
| `grass_moss_1/2/3.png` | 蘑菇绿，形状和草绿那三株完全一样，只换配色 |

## 在关卡里怎么用

关卡数据 `scenes/levels/level01.json` 的 `decor` 段：

```json
"decor": {
  "trees": [{"x": 9, "y": 25, "kind": "green", "bodies": 1}],
  "grass": [{"x": 2, "y": 25, "kind": "green", "n": 1}]
}
```

`y` 是树干底所在行，`bodies` 是 body 段数。改 `tools/make_level.py` 里的 `TREES` / `GRASS`
两个列表就能调整摆放，脚本会自动检查有没有和金币/史莱姆/方块撞位置。

植物画在 `Decor` 这个 `TileMapLayer` 上（`z_index = -5`），在地形后面、背景前面，
玩家会从树前面走过。所有植物**没有碰撞**。
